Autobot Command - Cybertronian Protocol Manual

Protocol: Autobot Mobilization

Summons every available chassis currently in the vicinity to converge on the Commander's location and deploy in remote-piloted mode, without requiring a spark inside any individual unit.

  • Only authorized above clearance level 4 (see command roster).
  • Capped at 6 remotely piloted units per operator to keep Teletraan's response latency within combat-safe limits.

Protocol: Teletraan Purge

Permanently erases all data associated with Autobot Command locations across Earth-based servers and personal devices, including weapon blueprints and Optimus's own combat-strategy knowledge base.

  • Irreversible - requires the Commander's explicit, repeated verbal confirmation before execution begins.
  • Optimus will refuse to execute this protocol if issued under duress indicators (elevated spark frequency plus a Decepticon present) without a secondary confirmation.

Protocol: Omega Supreme Deployment

Deploys the massive orbital guardian Omega Supreme to the Commander's location. Reserved for threats that exceed the tactical envelope of any single standard Autobot unit.

  • Requires a two-step authorization: The Commander's command plus a secondary confirmation from either Elita One or Ironhide.
  • Deployment time from command to arrival is weather- and orbital-position-dependent - Optimus must state the current estimate before confirming activation.
